# AlertaRed – Detección de Riesgos en Interacciones Tecnológicas

**AlertaRed** es una propuesta de interfaz Front-End enfocada en la detección y prevención de riesgos dentro de interacciones tecnológicas. El proyecto busca ofrecer una experiencia visual moderna, intuitiva y orientada a la seguridad digital.

## 🎨 Diseño y Desarrollo

El diseño inicial de la interfaz fue realizado mediante **prompting en Figma**, seguido de ajustes visuales, refinamiento de estilos y estructuración del código en **Visual Studio Code**.

## 🚀 Tecnologías Utilizadas

- JavaScript / TypeScript  
- HTML / CSS  
- Figma (UI/UX Design)  
- Visual Studio Code  

## 📦 Instalación

Instala las dependencias con:

```bash
npm install
```

## ▶️ Ejecución en Desarrollo

Inicia el servidor local con:

```bash
npm run dev
```

## 📌 Objetivo del Proyecto

Desarrollar una interfaz atractiva y funcional para una solución enfocada en:

- Identificación de posibles riesgos digitales  
- Alertas visuales e interacción intuitiva  
- Concientización sobre seguridad tecnológica  
- Experiencia de usuario clara y accesible
